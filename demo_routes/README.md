# 人工演示路线

这两份 JSON 用来体验导入、随机截取、配速修改及本地预览。它们在 `(0,0)` 附近由数学曲线构造，**不是校园真实路线，不含有效踩点，不能当作可直接提交的校园参考路线**。

- [演示路线 A：tasklist_9.json](tasklist_9.json)
- [演示路线 B：tasklist_6.json](tasklist_6.json)

在 GitHub 打开 JSON 后使用 Raw / Download raw file 保存，再到 GUI 点击“导入 history JSON”。下载整个仓库时已包含这些文件，可直接从 `demo_routes` 目录生成预览。

实际场地路线应优先通过自己的账号，在 GUI 的 History 页面下载自己已完成的记录。参见 [图文上手教程](../docs/QUICKSTART.md)。

公开包不包含任何人的真实跑步历史或凭据。生成发布包时会重新创建这两份人工 JSON。
